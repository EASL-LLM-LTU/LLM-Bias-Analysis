# LLM Bias Analysis with EASL 

**Aim:** Use EASL (Efficient Annotation of Scalar Labels) to evaluate and compare systematic biases in 3–4 LLMs. We will archive prompts, raw outputs, annotations, analysis, figures, and short workflow videos for full reproducibility.
